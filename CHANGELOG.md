# Change Log

All notable changes to ESLint MCP are documented in this file.

## 0.0.1

- Register the official ESLint MCP server with VS Code.
- Run the server through `npx @eslint/mcp@latest` over stdio.
- Add the `eslintMcp.version` setting for selecting a package version or npm distribution tag.
- Support VS Code 1.136.0 and later.
- Set the extension publisher identifier to `arcmantle`.
